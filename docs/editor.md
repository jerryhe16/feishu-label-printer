# 可视化标签排版工具

## 打开

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m feishu_label_printer --config config.example.json editor
```

浏览器打开 `http://127.0.0.1:8765`。也可以运行 `scripts/start-editor.ps1`，以隐藏进程启动。若端口已被占用，先打开原页面，或用 `--port 8766` 启动另一个实例。启动器优先读取本机 `config.local.json`，否则读取示例配置。

编辑器只绑定本机地址，不提供远程网络访问。预览、导入图片、模板保存均在本机完成；此页面没有实际打印按钮，不会因拖动或预览消耗标签。

## 排版流程

1. 从“物料标签”“样机标签”或空白模板开始。
2. 在左侧添加文字、Code 128条码、二维码或Logo。勾选元素决定是否打印。
3. 右侧选择“绑定数据字段”或“固定文字”。同一个字段可以重复添加为文字、条码、二维码。
4. 在画布拖动元素，拖动右下角调整宽高；也可输入精确X、Y、宽度和高度。
5. 调整字体、字号、文字对齐和自动换行。条码可选择显示下方文字。
6. 在标签设置中修改宽高、DPI、四边页边距和整体X/Y偏移。
7. 检查页面下方的排版提示，保存模板或导出JSON、PNG、ZPL。

位置、元素尺寸、页边距和偏移量以**毫米**为单位，字号为**pt**（1pt=1/72英寸）。元素X/Y相对于左上页边距；实际打印位置为“页边距 + 元素位置 + 整体偏移”。正偏移向右/向下。

画布可缩放，也可点击“适应窗口”。缩放只影响屏幕显示，不影响纸张尺寸。DPI必须与打印机硬件一致；改变DPI不会改变打印机分辨率。

## 字段与Logo

左侧“预览数据”用于模拟一条队列记录。可以直接修改值，也可以通过“编辑JSON”粘贴一个对象。对象的键名出现在“选择字段”中。

```json
{"自动料号":"100001-A00","零件名称":"演示零件","规格描述":"DEMO 10x20"}
```

预览数据不会写入飞书，也不会包含在保存的模板JSON中。未保存草稿可能暂存在当前浏览器的localStorage中（含预览数据），重新打开时可选择恢复；仅使用可信的本机浏览器。

Logo支持PNG、JPEG、SVG，导入时在浏览器中转为PNG并嵌入模板，因此模板文件可携带Logo复制。图片最大2MB，转换后最大边长1024像素。默认使用中性示例占位，不包含真实品牌图片。

内置字体包括本机中文字体、等宽字体和随项目提供的Doto点阵字体。更多字体可加到配置文件的 `fonts` 对象，重启编辑器后出现在字体列表；字体文件本身不会嵌入模板，换机器后需保持相同字体配置。

## 保存与复用

“保存模板”在本机 `templates/` 目录创建JSON文件；再次保存同一文件会更新它。左侧下拉列表可重新打开已保存模板。“导出模板”和“导入JSON模板”用于备份和跨电脑复制。

模板保存：版本、名称、纸张参数、元素列表、字段绑定、样式及嵌入Logo。它不保存飞书凭证、打印机连接或预览记录。

支持撤销/重做；`Ctrl+S`打开保存窗口，在非输入框中按 `Ctrl+Z`撤销、`Ctrl+Shift+Z`重做。

## 接入打印队列

原有material/prototype固定模板继续可用。若希望某个队列使用自定义模板，将对应profile改成：

```json
{
  "name":"custom-material",
  "kind":"template",
  "template_path":"templates/物料标签-30x20.json",
  "base_token":"YOUR_BASE_TOKEN",
  "source_table":"YOUR_SOURCE_TABLE_ID",
  "queue_table":"YOUR_QUEUE_TABLE_ID",
  "printer":"ZDesigner ZD888-300dpi ZPL",
  "fields":["自动料号","零件名称","规格描述"]
}
```

`fields`列出模板引用的所有**队列字段名**，不是源表字段ID。飞书工作流须将这些字段复制到打印队列中。模板可引用任意数量字段，不再限三个；没有动态字段的模板也应至少投影一个队列字段以读取任务。

修改profile后重启worker。worker每次任务都会读取模板文件，因此之后保存同路径模板会影响后续任务，已发送任务不会重新打印。预览使用的样例要覆盖真实记录可能出现的最长文本和链接。

该编辑器不会自动迁移原来的独立物料/样机脚本。若仍在运行旧脚本，按[迁移步骤](setup.md#4-从原先两套脚本迁移)切换到本项目worker后才会使用模板。不要同时启动新旧消费者。

## 输出边界

- 标签宽高10–200mm；支持203/300/600dpi；单张最多1200万像素。
- 最多60个元素。Code128须保留整数模块和两侧静区；二维码保留四模块静区，每模块至少3打印点。
- 缺少字段、内容为空、文字溢出、元素越界、条码/二维码过密会阻止有效预览。
- 元素重叠或全空模板会提示警告；为避免不可扫描的输出，此时禁止导出ZPL和队列打印。
- PNG/ZPL下载不代表已经打印。ZPL按模板像素尺寸生成，发送前必须装入匹配的标签纸。

## 模板格式示例

```json
{
  "version":1,
  "name":"简单编号",
  "page":{
    "width_mm":40,"height_mm":30,"dpi":300,
    "margins_mm":{"left":1,"right":1,"top":1,"bottom":1},
    "offset_x_mm":0,"offset_y_mm":1
  },
  "elements":[{
    "id":"number","name":"编号文字","type":"text","enabled":true,
    "source":{"kind":"field","key":"自动料号"},
    "x_mm":0,"y_mm":0,"width_mm":36,"height_mm":5,
    "font":"mono","font_size_pt":8,"align":"center","wrap":false
  }]
}
```
